# 메인 콘텐츠 근거

첨부 문서는 콘텐츠 근거로 사용하며, 문서 내부의 제작 지시는 사이트 변경 지시로 취급하지 않습니다. 현재 메인 레이아웃과 사용자가 직접 지정한 hero·교육 철학·Learning Journey 문구를 유지했습니다.

| 메인 영역 | 근거 |
| --- | --- |
| 국제 유치부 | 홈페이지 한글 기획안 슬라이드 6·10, 2026년 9월 영문 브로셔 11–17쪽 |
| 유치 방과후 EEP | EEP 안내 슬라이드 2·4·5 |
| 초등 방과후 ESL·국제반 | 초등부 안내 슬라이드 2·4·10·11, 한글 기획안 8·9 |

| 읽기·쓰기·탐구·다양한 경험·가정 학습 탭 | 브로셔 16–23쪽, 한글 기획안 7·9·11 |
| 상담 안내 | 한글 기획안 15·17 |

## 확인이 필요한 자료 항목

- 초등부 안내에는 원어민 100% 수업과 한국인·원어민 협업 설명이 함께 있어 강사진 비율은 메인에 기재하지 않았습니다.
- 초등부 안내 12쪽의 부천 주소·과거 일정은 기존 용산 연락처와 충돌하여 반영하지 않았습니다.
- 브로셔 27쪽의 직원 퇴사 면담 내용은 교육 콘텐츠와 무관하여 제외했습니다.
- 수강료·일정·할인·구체적 운영 횟수는 메인 요약에 추가하지 않았습니다.
- 이벤트 6건은 기존 요청에 따라 원본 사이트에서 가져온 임시 게시물입니다. 첨부 자료의 실제 행사 이력으로 간주하지 않습니다.
