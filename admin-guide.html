01

관리자 로그인 방법

운영 사이트에서 로그인하면 관리자 페이지와 홈페이지 내 관리 버튼을 함께 사용할 수 있습니다.

  1. 관리자 로그인 페이지를 엽니다.
  2. 발급받은 관리자 아이디와 비밀번호를 입력하고 로그인합니다.
  3. 관리 화면에서 작업할 게시판을 선택합니다. 홈페이지에서 작업하려면 홈페이지 보기를 누릅니다.
로그인 상태는 최대 8시간 유지됩니다. 작업을 마치면 로그아웃하세요. 비밀번호는 이 가이드에 기재하지 않으며, 분실하거나 변경이 필요하면 사이트 담당자에게 문의해 주세요.

02

관리자 페이지 사용방법

왼쪽 메뉴에서 관리 대상을 선택합니다. 모바일에서는 메뉴가 화면 상단에 표시됩니다.

메뉴할 수 있는 작업
이벤트 게시판행사 소식 등록·수정, 공개 설정, 순서 변경
유치부 캘린더유치부 일정을 날짜별로 등록·수정
초등부 캘린더초등부 일정을 날짜별로 등록·수정
팝업 관리홈페이지 팝업 이미지와 노출 기간 관리
상담 접수신청 확인, 상태 변경, 삭제, 엑셀 다운로드
교습비 관리푸터에서 열리는 교습비 이미지 등록
공통 정보 관리카카오톡·네이버 톡톡 주소 변경

저장을 눌러야 등록·수정 내용이 반영됩니다. 업로드가 끝났더라도 저장하지 않고 창을 닫으면 변경이 완료되지 않습니다.

03

홈페이지 설명

홈페이지는 DEWFORD 소개, 교육 프로그램 안내, 입학상담, 행사 소식과 학사 일정으로 구성됩니다.

  • 이벤트: 목록에서 글 제목이나 이미지를 누르면 상세 페이지를 볼 수 있습니다.
  • 캘린더: 유치부·초등부 일정을 구분해 확인하며, 날짜를 선택하면 해당 날짜의 일정이 표시됩니다.
  • 상담 신청: 홈, Contact, 입학상담 페이지의 양식이 같은 상담 접수함에 연결됩니다.
  • 푸터: 학원등록번호 옆의 교습비를 누르면 안내 이미지가 열립니다.
  • 영상: 화면에 들어오면 음소거 자동 재생하고 반복 재생합니다. 화면 밖에서는 일시정지합니다.
페이지의 일반 소개 문구·디자인·영상 파일은 현재 관리자 편집 대상이 아닙니다. 변경이 필요하면 사이트 담당자에게 페이지 주소와 수정 내용을 전달해 주세요.

04

교습비 등록 방법

  1. 교습비 관리를 엽니다.
  2. 교습비 안내 이미지에서 PNG, JPEG 또는 WebP 파일을 선택합니다. 한 파일은 20MB 이하로 준비합니다.
  3. 업로드된 미리보기를 확인하고 저장합니다.
  4. 홈페이지 푸터에서 교습비를 눌러 새 이미지가 보이는지 확인합니다.

교습비 이미지는 홈페이지 팝업 이미지와 별도로 관리합니다. 원본 크기를 기준으로 표시하며, 화면을 넘을 때만 축소됩니다.

05

이벤트 게시판 글 등록 및 수정 방법

사이트 내에서 등록·수정

  1. 먼저 관리자 로그인 후 이벤트 페이지로 이동합니다.
  2. 목록 위의 글쓰기를 누릅니다. 기존 글은 해당 글의 수정을 누릅니다. 상세 페이지에서도 로그인하면 최근 소식 아래 관리 버튼을 사용할 수 있습니다.
  3. 편집 팝업에서 제목, 날짜, 목록 소개글, 내용, 대표 이미지와 추가 사진을 작성합니다.
  4. 공개 여부를 확인하고 저장합니다. 홈페이지에서 글과 이미지를 확인합니다.

관리자 페이지에서 등록·수정

  1. 이벤트 게시판 관리를 선택합니다.
  2. 새 글은 + 글쓰기, 기존 글은 목록의 수정을 누릅니다. 제목 검색으로 글을 찾을 수 있습니다.
  3. 내용과 사진을 편집하고 공개 여부를 설정한 뒤 저장합니다.
  4. 게시판 보기를 눌러 결과를 확인합니다.

내용 편집기는 글자 크기·색상·굵기·목록·정렬 등을 지원합니다. 대표 이미지는 목록과 상세 화면에, 추가 사진은 상세 화면의 이미지 갤러리에 사용됩니다.

06

캘린더 게시판 글 등록 및 수정 방법

사이트 내에서 등록·수정

  1. 로그인 후 유치부 캘린더 또는 초등부 캘린더를 엽니다.
  2. 등록할 날짜를 선택하고 글쓰기를 누릅니다. 선택한 날짜가 편집 화면에 전달되므로 저장 전 날짜를 확인합니다.
  3. 제목, 내용과 필요한 이미지를 작성하고 공개 여부를 설정한 뒤 저장합니다.
  4. 기존 일정은 날짜를 선택해 일정 영역의 수정을 누릅니다.

관리자 페이지에서 등록·수정

  1. 관리 메뉴에서 유치부 또는 초등부 캘린더를 선택합니다.
  2. + 글쓰기 또는 기존 일정의 수정을 누릅니다.
  3. 일정의 날짜와 내용을 입력하고 저장합니다.
  4. 실제 캘린더에서 해당 날짜를 선택해 일정이 표시되는지 확인합니다.
캘린더 일정은 저장한 날짜에 표시됩니다. 다른 달에 저장했다면 달을 이동해 확인해 주세요. 유치부와 초등부 게시판도 구분해서 확인하세요.

07

이미지 확대 팝업과 사진 첨부

캘린더 일정의 사진과 이벤트 상세 페이지의 대표·추가 사진에는 우측 하단에 돋보기 아이콘이 표시됩니다. 사진을 누르면 확대 팝업이 열립니다.

  • 이벤트 상세에 사진이 여러 장이면 좌우 버튼이나 키보드 방향키로 이동합니다. 자동 슬라이드는 사용하지 않습니다.
  • 하단 미리보기 사진을 누르면 해당 사진으로 이동합니다. 사진이 많으면 가로로 스크롤할 수 있습니다.
  • 우측 상단 × 또는 Esc 키로 닫습니다.
  • 사진은 원본 비율을 유지하고 화면보다 클 때만 축소됩니다.

업로드할 사진 준비

PNG·JPEG·WebP 형식, 파일당 최대 20MB를 사용합니다. 추가 사진은 최대 20장입니다. 게시판 사진은 업로드 시 용량과 해상도를 자동 최적화하므로, 글자가 포함된 이미지는 업로드 후 미리보기와 확대 화면에서 읽을 수 있는지 확인하세요.

08

상담 신청과 관리자 확인 방법

방문자가 상담 신청하기

  1. 홈페이지, Contact 또는 입학상담 페이지의 상담 양식을 엽니다.
  2. 필수 항목(*)을 입력하고 관심 과정을 선택합니다. 개인정보 수집·이용에 동의합니다.
  3. 신청 버튼을 누르고 상담 신청이 접수되었습니다 안내를 확인합니다.

관리자가 접수 내역 확인하기

  1. 상담 접수를 엽니다. 새 접수는 최신순으로 표시됩니다.
  2. 이름·연락처·과정·상담 내용으로 검색하거나 새로고침합니다.
  3. 타이틀을 눌러 상세 팝업에서 연락처와 신청 내용을 확인합니다.
  4. 상세 팝업의 상담 단계를 접수 / 진행중 / 완료 중에서 선택하고 상태 변경을 누릅니다.

일괄 처리와 엑셀 다운로드

  • 행의 체크박스로 상담을 선택합니다. 상단 체크박스는 현재 페이지 전체를 선택합니다.
  • 상단 셀렉트 박스에서 상태를 고르고 상태 일괄 변경을 누르면 선택한 상담만 변경됩니다.
  • 일괄 삭제는 선택한 상담만 삭제합니다. 행 오른쪽 삭제 버튼은 해당 상담 한 건을 삭제합니다.
  • 엑셀 다운로드: 선택한 상담이 있으면 선택 내역만, 없으면 검색 조건과 관계없이 전체 내역을 받습니다. 파일은 Excel에서 열 수 있는 XML 형식입니다.
상담 접수 후 자동 이메일 발송은 제공하지 않습니다. 관리자 접수함을 확인해 남겨진 연락처로 안내해 주세요. 삭제한 내역은 관리자 화면에서 복구할 수 없으므로 삭제 전 대상 건수를 확인하세요.

09

홈페이지 팝업 관리

  1. 관리 메뉴에서 팝업 관리를 엽니다.
  2. 팝업 등록 또는 기존 항목의 수정으로 이미지를 첨부합니다.
  3. 필요한 경우 이미지 클릭 시 이동할 주소, PC 팝업 폭, 노출 시작·종료 시간을 지정합니다. 노출 시간은 한국 시간 기준입니다.
  4. 공개와 팝업 사용을 확인하고 저장합니다.
  5. 홈페이지에서 표시를 확인합니다. 오늘 하루 보지 않기를 선택했다면 해당 브라우저에서는 바로 보이지 않을 수 있으므로 다른 브라우저나 시크릿 창에서도 확인합니다.

노출 기간에 해당하는 공개·사용 중 팝업이 표시됩니다. 이미지가 여러 개면 자동으로 전환되며, 이전·다음 버튼과 모바일 스와이프도 사용할 수 있습니다.

10

학원 공통 정보·SNS 상담 링크 변경

  1. 공통 정보 관리를 엽니다.
  2. 학원이름, 연락처, 이메일, 주소, 학원등록번호를 수정하고 SNS 상담 링크 관리에서 카카오톡·네이버 톡톡 주소를 입력합니다.
  3. 저장 후 홈페이지를 새로고침합니다.
  4. 푸터와 연락처 안내에서 공통 정보가 변경되었는지 확인하고, 플로팅·SNS 상담 버튼을 눌러 의도한 채널이 열리는지 확인합니다.

카카오톡은 kakao.com 계열, 네이버 톡톡은 naver.com 계열의 주소를 사용합니다. 저장한 설정은 사이트 내 상담 버튼에 공통 적용됩니다.

11

공개 설정·순서·게시판 이동

  • 비공개: 공개 체크를 해제하고 저장하면 방문자에게 표시되지 않습니다. 작성 중인 글은 비공개로 저장한 뒤 다시 수정할 수 있습니다.
  • 순서 변경: ↑·↓ 버튼으로 게시글의 표시 순서를 조정합니다.
  • 게시판 이동: 이동 버튼에서 목적지 게시판을 고릅니다. 캘린더로 옮길 때는 표시할 날짜도 확인합니다.
  • 삭제: 확인 창의 글 제목·건수를 확인합니다. 화면에서 되돌리는 기능은 제공하지 않습니다.
  • 동시 편집: 다른 화면에서 먼저 저장한 경우 최신 내용으로 다시 불러옵니다. 여러 탭에서 같은 글을 동시에 편집하지 않는 것이 좋습니다.

12

문제가 생겼을 때

상황확인할 내용
홈페이지에서 관리 버튼이 안 보여요같은 운영 사이트에 로그인했는지 확인하세요. 로그인 유지 시간이 지났다면 다시 로그인합니다.
저장한 글이 안 보여요저장 성공 안내, 공개 여부, 게시판 종류와 날짜를 확인하고 새로고침합니다.
상담 내역을 불러오지 못해요새로고침 후에도 동일하면 사이트 담당자에게 화면 주소와 오류 문구를 전달합니다. DB 연결 또는 업데이트 확인이 필요할 수 있습니다.
사진 업로드에 실패했어요지원 형식·파일 용량·네트워크를 확인합니다. 저장 공간 관련 오류는 담당자에게 문의합니다.
변경 내용 충돌 안내가 떠요최신 내용을 확인한 뒤 다시 편집·저장합니다.
신청이 접수되지 않았다고 나와요성공 안내 없이 접수가 끝난 것으로 간주하지 마세요. 잠시 후 재시도하거나 전화로 안내합니다.

관리할 때 함께 확인하기

  • 글·일정을 등록한 뒤 PC와 모바일에서 제목, 사진, 날짜를 확인합니다.
  • 상담 신청은 개인정보가 포함되어 있으므로 다운로드 파일은 필요한 담당자에게만 전달합니다.
  • 공용 컴퓨터에서는 작업 후 로그아웃하고 내려받은 상담 파일도 정리합니다.
